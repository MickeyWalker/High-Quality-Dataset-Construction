# 第四章：高质量数据集建设方法与实践

## Core Idea
本章是全书的方法论核心：从建设模式、核心环节、核心技术、质量评价四个层面给出可操作的工程方案，覆盖数据集建设全生命周期。核心是"场景驱动"与"数据驱动"两种模式的选择，以及六环节闭环、五类核心技术、三维质量评价体系。

## Frameworks Introduced
- **两种建设模式**:
  - **场景驱动模式**: 以明确业务需求/场景为起点，"需求拆解→数据设计→数据采集→数据处理→数据质量检测→数据运营"闭环。目标导向，数据质量高、针对性强，易形成闭环反馈。**当前推荐选择**（更契合高质量数据集建设的核心目标）
  - **数据驱动模式**: 以积累的多源异构数据为基础，主动探索关联分析与价值挖掘，反向发现需求。过程导向，快速形成大规模数据资产，适合通用大模型/预训练任务
- **建设全生命周期六环节**: 数据需求 → 数据规划 → 数据采集 → 数据预处理 → 数据标注 → 模型验证（各环节按序展开，同时互相反馈、迭代优化）
  - 数据需求：明确范围、内容、可用性、质量模型
  - 数据规划：设计数据架构、制定具体计划（采集/预处理/标注/验证）、预估工作量
  - 数据采集：确定采集方式（复用现有/生成/购买/新采集）、测试方法、测量质量
  - 数据预处理：转换/验证/清洗/聚合/抽样/特征创建/特征选择/信息丰富
  - 数据标注：明确规程规范、确定技能资源、监督质量管理
  - 模型验证：性能达标即满足；不达标按"数据 vs 算法归因→反馈上游→迭代环节→重建模型"四步走
- **五大核心技术**: 数据采集（多源异构融合/边缘侧/生成模型辅助合成）、数据转换（规则引擎/语义理解与知识图谱/多模态）、数据清洗（规则自动化/机器学习智能清洗/大规模分布式）、特征选择（统计过滤/嵌入式包装/深度学习自动提取）、数据标注（半自动化/众包分布式/主动学习与模型辅助）
- **三维质量评价指标体系**（参考《高质量数据集 质量评测规范（征求意见稿）》）:
  - 说明文档指标：基本信息/内容特征/建设过程/应用说明完整性
  - 数据质量指标：格式规范性、安全规范性、标注规范性、结构完整性、内容真实性、内容一致性、类型一致性、内容干净性
  - 模型应用指标：内容多样性、规模完整性、内容时效性、标注准确性、模型适配性

## Key Concepts
- **以评促建、以评促用**: 通过质量评价倒逼数据生产和管理环节提质增效
- **评价闭环三阶段**: 评估准备 → 指标体系构建与实施 → 综合评价与反馈应用
- **质量评价工作体系四原则**: 全面性、客观性、可操作性、动态适应性
- **合成数据**: 针对稀缺/敏感场景，用仿真、统计、GAN、扩散模型模拟生成符合真实分布的数据
- **主动学习**: 利用模型预测指导标注优先级，提高标注资源利用效率

## Mental Models
- 用"数据 vs 算法归因"处理模型不达标：先判断是数据集的问题还是算法的问题，再决定动哪里
- 用"先有需求再建数据"（场景驱动）作为默认选择，除非目标是通用大模型
- 用"数据质量是全生命周期的"看待质量问题：采集环节引入的问题会传导到下游

## Anti-patterns
- **跳过模型验证环节**: 建完数据不验证性能 → 无法确认数据集是否满足要求，也断掉反馈闭环
- **预处理环节一刀切**: 不按需选择转换/清洗/抽样等过程 → 要么内容损失过大，要么信息冗余
- **评价只看数据本体**: 忽视说明文档和模型应用维度 → 数据可用但不可用（没人看得懂）、不可复用

## Worked Example
**模型验证不达标处理流程**（原文逐步决策）：
1. 确定数据集（相比算法）是否使模型性能未达预期的根本原因
2. 分析模型验证发现的数据质量问题，反馈给上游环节改进
3. 重复数据规划、采集、预处理、标注等环节以提升数据质量
4. 重建人工智能模型，重新评估性能

**数据采集方式决策**（按数据可得性分支）：
- 已有数据可直接再利用 → 获取和组合现有数据集
- 现有数据可转化满足要求 → 转换改造
- 可通过购买/许可获得 → 采购
- 数据稀缺/敏感 → 生成数据（模拟、合成）
- 以上皆不满足 → 新采集（传感器、手动输入），并测试调整采集方法

**质量评价指标应用示例**：内容真实性要求——非合成数据能追溯到采集源头、无未说明篡改；合成数据能追溯到生成算法和过程、符合目标场景真实数据分布规律。

## Key Takeaways
1. 默认选场景驱动模式；只有通用大模型/预训练才考虑数据驱动
2. 六环节闭环+反馈是建设骨架，模型验证是闭环的关键闸口
3. 五大技术各有适用场景：稀缺数据用合成，复杂数据用智能清洗，海量标注用众包
4. 质量评价三维度（文档/数据/应用）缺一不可，评价结果要反馈形成闭环
5. 评价体系构建遵循全面性、客观性、可操作性、动态适应性四原则
